BestBefore
GitHub ↗

Every answer through your gateway, checked against today's web.

A Bifrost plugin that finds the time-sensitive claims in a model's answer, re-verifies them with Tavily, scores how fresh each one is, and keeps stale answers out of the semantic cache.

Requests go to /v1/chat/completions on your Bifrost gateway. The check tab uses the bestbefore/verify model the plugin adds.
